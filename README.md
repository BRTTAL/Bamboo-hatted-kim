# นักรบหมวกไผ่ (Bamboo Hat Warrior)

เกมแอ็กชัน 2D side-scroller เล่นในเบราว์เซอร์ ไม่ต้องติดตั้งและไม่ต้องมีเซิร์ฟเวอร์ — ทั้งเกมอยู่ในไฟล์ `index.html` ไฟล์เดียว

## วิธีเล่น
เลือก Mobile หรือ PC แล้วเลือกโหมด (เนื้อเรื่อง 3 ด่าน / ไม่มีที่สิ้นสุด)

| PC | ทำอะไร |
|---|---|
| A / D หรือ ← → | เดิน |
| W / Space / ↑ | กระโดด |
| เมาส์ | เล็งทิศ (ตัวละครหันและพุ่งตามเมาส์) |
| คลิกซ้าย (หรือ J) | ฟัน / แพรี่ (คูลดาวน์ 1 วิ, แพรี่เพอร์เฟคจะรีคูลดาวน์และคืนชาร์จพุ่ง) |
| คลิกขวา (หรือ K / Shift) | พุ่ง (สูงสุด 3 ครั้ง ชาร์จ ~3 วิ) |
| Q | สกิลชักดาบ (เมื่อแถบเต็ม) คลิกล็อกเป้า แล้วกด Q อีกครั้งเพื่อปล่อย |
| Esc / P | เมนูตั้งค่า |

มือถือ: ใช้ปุ่มบนหน้าจอ (หมุนจอเป็นแนวนอน) แตะที่ศัตรูเพื่อล็อกเป้าตอนใช้สกิล

## เปิดให้คนอื่นเล่นด้วย GitHub Pages
1. สร้างรีโปใหม่บน GitHub (Public)
2. อัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมด (`index.html`, `.nojekyll`, `README.md`) ไปไว้ที่ root ของรีโป
3. ไปที่ **Settings → Pages** เลือก **Deploy from a branch** → Branch: `main`, Folder: `/ (root)` → Save
4. รอ 1–2 นาที เกมจะเปิดที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อรีโป>/`

เปิดทดสอบในเครื่องได้โดยดับเบิลคลิก `index.html`

## หมายเหตุ
- ใช้ฟอนต์ Noto Sans Thai จาก Google Fonts (ถ้าออฟไลน์จะใช้ฟอนต์ระบบแทน)
- เสียงทั้งหมดสร้างด้วย Web Audio API ไม่มีไฟล์เสียง และจะเริ่มหลังกดเลือกอุปกรณ์ (ข้อกำหนดของเบราว์เซอร์)
